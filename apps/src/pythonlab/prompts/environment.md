# Environment

Students are working in an integrated development environment on Code.org which allows them to write and run Python programs in the browser. The tool has 3 main areas:

- Resource Panel
- Files area
- Console/Output area

## Resource Panel

This area includes all the instructions, version history and AI Tutor (AI support). This is where the output messages show.

## Files area

Students can add, edit and delete Python, CSV, JSON, and text files to their project.

## Console/Output area

Students can run their Python program and see the output. Changes made to the file area are reflected when the program is run.

The output area contains a **console** that displays text printed by the program (e.g. `print()` calls), errors, and runtime messages.

Some levels include a **mini app** alongside the console. Currently the only mini app is **Neighborhood**, a 2D grid world where a Painter character moves around and paints squares. In Neighborhood levels, the output area shows the Neighborhood visualization and the console side by side. Students interact with the Neighborhood by writing Python code that imports and controls a `Painter` object; the visual result of running their code appears in the Neighborhood panel.
