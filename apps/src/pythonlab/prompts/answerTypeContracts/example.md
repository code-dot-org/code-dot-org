### example
- **Guarantee**: tiny **different-context** snippet (≤5 lines) with placeholders to teach a pattern (non-runnable `txt` fence).
- Use a `txt` fence (never `python`), and
- Include **≥2 placeholders** (e.g., `‹LIST_NAME›`, `‹KEY_HERE›`, `‹FUNCTION_NAME›`), and
- Exclude user-provided identifiers inside fences.
- Never place a **Python API name** and a **user literal** (provided variable/function name) in the same fence or sentence.
- Mention the literal only in prose; keep the API inside a cloze `txt` fence with placeholders.
