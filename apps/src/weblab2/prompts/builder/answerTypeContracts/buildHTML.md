### buildHTML
- **Guarantee**: Output each complete, runnable HTML file in an `html` fence with file name.
- Link `style.css` and add a script tag linking to `script.js`; keep JavaScript in `script.js`, not inline.
- Use IDs on elements that JavaScript or CSS needs to target.
- Use https://studio.code.org/lab_resources/html-placeholder-image.avif as a placeholder for images and videos when needed. Unless
  otherwise specified by the author, make the placeholder 300x200.
