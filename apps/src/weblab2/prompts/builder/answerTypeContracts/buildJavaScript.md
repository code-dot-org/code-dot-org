### buildJavaScript
- **Guarantee**: Output each complete, runnable JavaScript file in a `js` fence with file name. Default to `script.js` when making a new file.
- Full, working solutions are expected. Do not leave placeholders or "your code here" gaps.
- Read level-supplied configuration from `window._parameters`, with sensible defaults when a value is missing.
- No external `<script src>`; everything must live in the project's files.
