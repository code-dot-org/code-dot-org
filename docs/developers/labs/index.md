A lab is a frontend runtime (Maze, App Lab, Music Lab, and so on) that renders inside a level page. The runtime contract between Rails and the client-side lab code, the Blockly fork, and the steps to add a new lab are documented here.

- [How a level loads](/developers/labs/how-a-level-loads/) -- from controller to `appOptions` to the webpack entry point.
- [Blockly fork](/developers/labs/blockly-fork/) -- what the fork changes and how updates flow.
- [Add a lab](/developers/labs/add-a-lab/) -- the checklist for wiring a new lab into the platform.
