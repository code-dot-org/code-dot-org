Maintenance runbook for the documentation system: conventions, verification, deploy updates, reconciliation, and agent orchestration.

- [Corpus and conventions](/developers/documentation/corpus-and-conventions/) -- how the documentation is organized, what the frontmatter means, and which stylebook to load.
- [Verification](/developers/documentation/verification/) -- journeys, screenshots, evidence files, and evidence grades.
- [Update after a deploy](/developers/documentation/update-after-deploy/) -- find affected pages, reinvestigate, refresh screenshots, and open a PR.
- [Periodic reconciliation](/developers/documentation/periodic-reconciliation/) -- detect vanished sources, failing journeys, orphan images, and dangling links.
- [Agent orchestration](/developers/documentation/agent-orchestration/) -- the domain-owner model, the working area, and what is disposable.

For the docs site commands (build, preview, evidence check), see [docs/README.md](https://github.com/code-dot-org/code-dot-org/blob/staging/docs/README.md).
