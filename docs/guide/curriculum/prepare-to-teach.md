Before teaching a unit, review the lesson plans, vocabulary, and materials it provides.

## Open the unit overview

From a course overview page, select any unit title. The unit overview lists every lesson in the unit, with a progress indicator if your section is already working through it.

## Vocabulary, standards, and code tabs

The unit overview has tabs along the top:

- **Vocabulary** -- every term introduced in the unit, organized by lesson.
- **Standards** -- the standards this unit covers, with links to the lessons that address each one.
- **Code** -- programming constructs introduced in each lesson.
- **Resources** -- downloadable handouts and links.
- **Calendar** -- appears when a section is assigned to this unit; maps lessons to school weeks.

## Lesson plans

Select any lesson title to open its plan. The plan includes:

- **Overview** -- learning objectives, preparation steps, and a time estimate.
- **Teaching guide** -- step-by-step activities, discussion prompts, tips, and assessment opportunities.
- **Materials** -- handouts, links, and resources needed for the lesson.

Many lessons include slides you can project in class. Select **View slides** on the lesson plan page to open them.

## Download a PDF for offline use

CodeAI generates printable PDFs for units in the **stable** published state: teacher lesson plans, student lesson plans (where available), a unit overview, and a resource rollup. Look for a download link on the unit overview or on an individual lesson plan. If no link appears, the unit may not be in the stable state yet.

## View the answer key

**Applies to:** [verified teachers](/guide/professional-learning/become-a-verified-teacher/).

On levels that have an exemplar or answer key, a link appears in the teacher panel or alongside the instructions. The exemplar is not visible to students.
