CodeAI generates personalized certificates when a student finishes a course or an Hour of Code activity.

## Print certificates for a section

1. On your teacher home page or in section settings, select **Print certificates**.
2. Select the section and the course or activity.
3. CodeAI generates a certificate for each student in the section.
4. Use your browser's print dialog to print the batch or save it as a PDF.

![The certificates page showing the section and course selectors](images/print-certificates-certificates-page.png)

## Print certificates without student accounts

For students who completed an Hour of Code without signing in, visit the certificates page and enter student names manually.

## How students get their own certificate

1. On the congratulations page at the end of a course or activity, enter your name in the text field.
2. Select **Submit**. A personalized certificate appears.
3. Select **Print Certificate** or use the browser's print dialog to save it.

No account is needed for an Hour of Code certificate. Each certificate has a unique URL for sharing.
