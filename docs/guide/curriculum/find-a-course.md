The curriculum catalog lists every course available on CodeAI. Use it to compare courses and decide what fits your classroom.

## Browse the curriculum catalog

1. Select **Course Catalog** in the top navigation bar.
2. Use the filter dropdowns to narrow the list:
   - **Grade** -- one or more grade bands (for example, Grades 6-8).
   - **Subject and topic** -- computer science, AI, data science, or other topics.
   - **Curriculum** -- Course, Module, Standalone Unit, or Hour of Code.
3. Select **Clear filters** to reset.

Each card shows the course name, recommended grades, and a short description. Anyone can browse the catalog, including visitors who are not signed in. Signed-in teachers also see an **Assign** button on each card.

The catalog lists courses in the **preview** or **stable** published state with a student audience. If a course you expected is missing, see [Who can see this course](/guide/curriculum/who-can-see-this-course/).

## Review a course

Select any card to open the course overview. The overview shows a description, recommended grade levels, every unit with titles and summaries, and links to standards alignment and reference guides.

If the course has more than one version year (for example, '24-'25 and '25-'26), a version selector appears near the top. The catalog defaults to the latest stable version.

## Try the incubator

The incubator has experimental activities that CodeAI is actively developing. Select **Incubator** in the top navigation bar.

The incubator link is visible to English-speaking teachers and does not appear for students or in other languages. Incubator activities may lack full lesson plans, standards alignment, or localization, and may change or be removed.
