---
title: Assign a course
description: Assign a course to a section so students see it when they sign in.
type: task
---

When you assign a course to a section, that course appears on your students' home page and CodeAI takes each student to the first unfinished lesson automatically. Changing an assignment does not affect student progress on other courses.

## Prerequisites

- At least one section. See [Create a section](/guide/sections/create-a-section/).

## Assign from the curriculum catalog

1. Select **Course Catalog** in the top navigation bar.

   ![The curriculum catalog page showing course cards with grade, subject, and Assign buttons](images/assign-a-course-course-catalog.png)

2. Use the filters to narrow the list by grade, subject, or curriculum type.
3. Select **Assign** on the course card.
4. Check the sections you want to assign the course to.
5. Select **Assign** to confirm.

CodeAI assigns the most recent recommended version of the course.

## Assign from a course or unit overview

1. Open the course overview or unit overview.
2. Select **Assign** near the top of the page.
3. Choose one or more sections and confirm.

## Assign during section creation

The section setup wizard offers a curated list of courses organized by grade band (elementary, middle, high). Selecting one assigns it immediately.

## Change or remove an assignment

1. From your home page, select the section, then select **Settings**.
2. Change the assigned course using the course selector.

Changing the assignment does not delete student progress on the previous course.

## Which courses can be assigned

A course can be assigned when it is marked assignable by CodeAI and its audience matches the section type. Most K-12 courses allow any teacher to assign them. Some professional-learning courses require specific permissions. See [Who can see this course](/guide/curriculum/who-can-see-this-course/).
