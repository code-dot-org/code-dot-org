The projects page lists every project you have created, and lets you start new ones. Select **Projects** in the top navigation bar or go to [studio.code.org/projects](https://studio.code.org/projects).

![The projects page showing the hero banner, the Learn more about labs card, and the Create a new project section with lab cards](images/managing-your-projects-projects-page.png)

## My Projects

Your projects appear under **My Projects**, newest first.

![The My Projects tab selected, showing a table with three projects in different labs (Dance Party, Sprite Lab, Artist) with their name, type, last edited date, and Quick Actions columns](images/managing-your-projects-gallery-filters.png)

- Select a project's name to open it.
- Select the pencil icon next to a name to rename it.
- Open the actions menu (three dots) for **Delete**. Deleted projects can be restored for a limited time.

![The actions menu for a project showing Rename, Remix, and Delete options](images/managing-your-projects-project-actions-menu.png)

If you do not see any projects, select a lab card under **Start a new project** to create one.

## Start a new project

Each project lives in a lab (Artist, Sprite Lab, App Lab, Game Lab, Music Lab, Python Lab, or Web Lab). Select **New project +** in the top-right corner or choose a lab on the projects page. The project opens in the editor and saves automatically as you work.

![The Create a new project section showing lab cards organized by Blocks (Sprite Lab, Artist, Music Lab) and Beyond Blocks (Game Lab, App Lab, Python Lab, Web Lab)](images/managing-your-projects-new-project.png)

If you are under 13, App Lab and Game Lab are not available unless your teacher has enabled sharing for your class.

## Version History

Your project is saved automatically as you work. To restore an earlier version:

1. Open your project in the editor.
2. Select **Version History** in the project header.
3. Browse the list of saved versions, each showing when it was saved.
4. Select **Restore** next to the version you want.

The later versions stay in the history, so you can switch back. **Version History** is available on standalone projects and on levels that save to a project. It does not appear on course puzzle levels with no project attached.

## Backpack

The backpack lets you carry code between projects. Drag code from the editor into the **Backpack** icon, or use the backpack menu. Open another project and drag the saved code out. Items stay in your backpack across sessions until you remove them.
