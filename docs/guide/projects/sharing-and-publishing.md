Share a project with a link, publish it to the public gallery, remix another student's project, or report inappropriate content.

## Share your project

Anyone with the link can see your project and try it -- they do not need a CodeAI account.

1. Open your project in the editor.
2. Select **Share** in the project header.
3. In the share dialog, select **Copy link to project**.

   ![The share dialog showing the copy-link and send-to-phone buttons](images/sharing-and-publishing-share-dialog.png)

4. Paste the link wherever you want to share it.

If a personal-information warning appears, review your project before sharing. CodeAI checks for names and other personal details and asks you to remove them.

### Send to phone

In the share dialog, select **Send to phone** and enter a phone number. CodeAI sends a text with the link.

### Embed in another page

If the project type supports embedding, the share dialog shows an `<iframe>` snippet. Copy it and paste it into any web page.

### If sharing is not available

See [Can I share this?](/guide/projects/can-i-share-this/) for the rules that determine whether the share button is enabled.

## Publish to the gallery

Publishing puts your project in the public gallery where anyone can find, try, and remix it. Only you can publish or unpublish your own projects. Make sure your project does not contain personal information or inappropriate content.

1. Go to your [project list](/guide/projects/managing-your-projects/).
2. Select **Publish to Public Gallery** on the project you want to publish.

To remove it later, select **Unpublish** from the same menu.

### If you cannot publish

The most common reasons:

- **App Lab or Game Lab:** you must be 13 or older, or your teacher must have enabled sharing.
- **Sprite Lab with uploaded images:** cannot be published.
- **Web Lab, Algebra, Minecraft Code Builder:** cannot be published.

See [Can I share this?](/guide/projects/can-i-share-this/).

## Browse the public gallery

The public gallery at [studio.code.org/projects/public](https://studio.code.org/projects/public) shows projects students have published. Projects are organized by lab type. You do not need to be signed in.

## Remix a project

Remixing creates your own copy that you can change without affecting the original.

1. Open a shared project by visiting its link or selecting it in the gallery.
2. Select **Remix** in the project header.

   ![The Remix button on a shared project](images/sharing-and-publishing-remix-button.png)

A new project opens in the editor and appears in your [project list](/guide/projects/managing-your-projects/). If the **Remix** button is not visible, the project owner may have uploaded a personal image (Sprite Lab), which disables remixing.

## Report a project

If you see a shared project with inappropriate content, you can report it.

1. Open the shared project.
2. Select **Report Abuse** below the project.
3. Fill in the form: your email, the type of problem, and a short description.
4. Complete the CAPTCHA and select **Submit**.

Reports are reviewed by CodeAI staff. If confirmed, the project is blocked and no longer accessible through its share link. You do not need to be signed in to report a project.
