A code library is a collection of functions published for others to use. Import one into your App Lab project to call its functions directly.

**Applies to:** App Lab.

## Import a library

1. Open your App Lab project.
2. In the code editor, open the library manager.
3. Search for a library by name or paste a library ID.
4. Select **Add** to import it.

The library's functions are now available in your code. Call them as documented by the library author.

## Publish your own library

1. Open the App Lab project that contains the functions you want to share.
2. Open the library manager.
3. Select **Publish** and confirm.

Your teacher can also share a library with their entire class.
