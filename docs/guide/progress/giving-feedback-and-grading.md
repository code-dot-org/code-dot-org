After a student submits work, you can leave written feedback, grade with a rubric, or set up peer review groups.

## Prerequisites

- A section with students who have submitted work.

## Leave feedback

1. Open the student's work from the [progress grid](/guide/progress/tracking-progress/) by selecting a level cell.

   ![The teacher view of a student's Free Response level, showing the rubric with evidence levels, the student's written response, and the Teacher Panel listing all students in the section](images/giving-feedback-and-grading-student-work-feedback.png)

2. Select the **Feedback** tab in the instructions panel.

   ![The Feedback tab on a Web Lab level showing the Teacher Feedback heading, Keep working checkbox, comment textarea, and Save and share button, with the Teacher Panel listing students on the right](images/giving-feedback-and-grading-weblab-teacher-view.png)

3. Type your comment in the feedback area.

   ![The feedback textarea with placeholder text](images/giving-feedback-and-grading-feedback-input.png)

4. Select **Save and share**.

   ![The Save and share button](images/giving-feedback-and-grading-submit-feedback-button.png)

The student sees the feedback the next time they open the level.

### Ask a student to revise

1. In the feedback area, check **Keep working**.
2. Select **Save and share**.

The student's progress icon changes to "keep working" and they see your note when they reopen the level.

## Evaluate with a rubric

Some levels include a rubric with learning goals. You evaluate each student's work against these goals and assign an evidence level.

### Grade a student

1. Open the student's work from the [progress grid](/guide/progress/tracking-progress/).
2. In the rubric panel, select an evidence level for each learning goal: **Extensive Evidence**, **Convincing Evidence**, **Limited Evidence**, or **No Evidence**.
3. Optionally type written feedback.
4. Select **Submit**.

The student sees both the rubric score and any written feedback.

### Request AI evaluation

**Applies to:** rubric-backed levels with AI evaluation enabled; [verified teachers](/guide/professional-learning/become-a-verified-teacher/).

1. In the rubric panel, select **Run AI Assessment for Project** to evaluate one student, or **Run AI Assessment for Class** to evaluate all students at once.
2. The AI analyzes each student's code and suggests an evidence level for each goal with a confidence indicator.
3. Review, adjust, or override each suggestion.
4. Submit your final evaluation.

The AI evaluation is a suggestion; you always have the last word. There is a limit of 10 AI evaluations per student per project. See [Review an AI evaluation](/guide/ai/review-ai-evaluation/) for details.

### What students see

Students see the rubric's learning goals before and after submission. After your evaluation, they see the evidence level you assigned and any written feedback. They do not see the AI's raw suggestions.

## Set up code review groups

Code review groups let students read each other's code and leave comments.

1. Open your section in the teacher dashboard.
2. Navigate to the code review groups page.
3. Assign students to groups (typically two to four students each).
4. Save the groups.

Students in the same group can see each other's projects and leave comments. Sharing is automatically enabled for grouped students. You can reassign or remove groups at any time.
