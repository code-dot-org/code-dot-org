---
title: Change the site language
description: How to switch CodeAI to a different language.
type: task
---

CodeAI is available in dozens of languages.

1. Scroll to the bottom of any page.
2. Open the language dropdown in the footer.
3. Select the language you want.

The page reloads in the new language. Your choice is saved and applies across the site until you change it again.

Menus, buttons, and instructions appear in the selected language. Code blocks in Blockly labs are also translated. Code you type in text-mode labs (App Lab, Game Lab, Java Lab) stays in English because programming languages use English keywords.
