How you sign in depends on how the account was set up.

## Sign in with email and password

1. Go to [studio.code.org/users/sign_in](https://studio.code.org/users/sign_in).
2. Enter your email address or username in the **Email or Username** field.
3. Enter your password.
4. Select **Sign in**.

### Use Google, Microsoft, Facebook, Clever, or ClassLink

Select the matching button on the sign-in page -- for example, **Continue with Google**. You complete sign-in on that provider's page and return to CodeAI automatically. If this is the first time using that provider with CodeAI, you may be asked to authorize the connection.

### Forgot your password

Select **Forgot your password?** on the sign-in page.

![The Forgot your password? link on the sign-in page](images/sign-in-forgot-password-link.png)

See [Reset your password](/guide/getting-started/reset-your-password/).

## How students sign in with a section code

**Applies to:** sections with the Picture or Word login type.

The teacher or the student's sign-in card has the six-letter section code.

### Picture password

1. Go to [studio.code.org/users/sign_in](https://studio.code.org/users/sign_in).
2. Under **Section code**, type the six-letter code and select **Go**.

   ![The Section code field at the bottom of the sign-in page, below the email login form](images/sign-in-section-code-field.png)

3. Select your name from the list.
4. Select your secret picture from the grid.

   ![The picture password screen showing the student's name, a grid of cartoon character icons to choose from, and a Sign in button](images/sign-in-picture-password-grid.png)

### Word password

1. Go to [studio.code.org/users/sign_in](https://studio.code.org/users/sign_in).
2. Under **Section code**, type the six-letter code and select **Go**.
3. Select your name from the list.
4. Type your two secret words.

   ![The secret words screen showing the student's name, a text field to enter secret words, and a Sign in button](images/sign-in-word-password-entry.png)

### If you do not know your section code

Ask your teacher. Teachers can find the code on the section management page.

### Add your own email and password

You can add an email address and password to a teacher-managed account so you can sign in without the section code. See [Upgrade to a personal account](/guide/getting-started/upgrade-to-a-personal-account/).

## Sign in from a learning management system

If the teacher assigned CodeAI through an LMS such as Canvas or Schoology, open the assignment inside the LMS. CodeAI signs the student in automatically. If the student does not already have a CodeAI account, one is created during the first launch.

### Link an existing CodeAI account

If the student already has a standalone CodeAI account, they may be asked to link the LMS identity to it. Follow the on-screen instructions.

### If the assignment does not open

The teacher or school administrator may need to finish the LMS integration setup. See [Connect your LMS](/guide/integrations/connect-your-lms/).
