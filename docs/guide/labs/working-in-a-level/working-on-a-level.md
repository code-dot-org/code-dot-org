Every coding level has instructions, a workspace for your solution, and a play area that shows the result. This page covers the controls available in most levels.

## Run your code

1. Select **Run**.

   ![The Run button](images/working-on-a-level-run-button.png)

   Your program executes in the play area. If the level has a goal, a dialog tells you whether you passed.

2. If the dialog says you passed, select **Continue** to move to the next level.

Some labs use a different label for the same button. In Music Lab it says **Play**. The button is always in the same position, below or beside the play area.

## Reset or start over

### Reset after running

After you select **Run**, a **Reset** button replaces it.

![The Reset button](images/working-on-a-level-reset-button.png)

Select **Reset** to stop the program and return the play area to its starting state. Your blocks and code stay where they are.

### Start over

Select **Start Over** in the toolbar below the workspace to erase all your work on this level and begin from scratch.

![The Start Over button](images/working-on-a-level-start-over.png)

This does not affect other levels.

### Restore an earlier version

In labs that save your work as a project (App Lab, Game Lab, Web Lab, and others), select **Version History** in the project menu to browse and restore a previous snapshot. See [Your project list](/guide/projects/managing-your-projects/).

## Get a hint

### Instructions

The instructions appear when the level loads.

![The Instructions button in the toolbar](images/working-on-a-level-instructions-panel.png)

Dismiss them with **OK**. Reopen them by selecting **Instructions** in the toolbar above the workspace.

### Hints

If the level has hints, a lightbulb icon appears near the instructions. Select it to reveal the next hint. Hints appear one at a time, each with more detail than the last. Not every level offers hints.

### Read-aloud

Some levels show a speaker icon next to the instructions. Select it to hear the instructions read aloud (English by default).

## Watch a video

Some lessons include a short video before you start coding.

If your school blocks YouTube, CodeAI tries a fallback player at videos.code.org. If neither player loads, ask your teacher or school IT staff to allow access to youtube.com or videos.code.org.

Captions: if available, select the **CC** button in the video player controls.

## Switch between blocks and text

**Applies to:** App Lab, Game Lab.

A toggle below the workspace lets you switch between dragging blocks and typing JavaScript.

![The Show Code toggle button below the workspace](images/working-on-a-level-show-code-toggle.png)

Select **Show Text** to see the text editor. Select **Show Blocks** to switch back. Your code is the same in both views.

If your text contains JavaScript that has no block equivalent, the editor stays in text mode and shows a warning. Remove or rewrite the unsupported syntax to return to blocks. Your mode preference is remembered per level.

Block-only labs (Maze, Artist, Dance Party, and others) do not show this toggle.

## Choose an activity

Some levels offer a choice of activities instead of a single puzzle. Select the one you want to try. Completing any one of the options counts as finishing the level. You can go back and try a different choice later.
