CodeAI has a built-in reference for every programming block and function in each lab.

## Browse the reference

1. Go to [studio.code.org/docs](https://studio.code.org/docs).
2. Select the lab you are working in (for example, App Lab, Game Lab, or Sprite Lab).
3. Browse the list. Each entry shows the name, a description, example code, and the parameters it accepts.

## Find a dataset

The data library lists ready-made datasets you can use in data-science projects. Go to [studio.code.org/docs/concepts/data-library](https://studio.code.org/docs/concepts/data-library) and browse by topic.
