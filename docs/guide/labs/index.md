Labs are the programming environments where students build projects and complete levels. Each page below describes a lab's workspace regions, tools, and features.

### Lab reference

- [App Lab](/guide/labs/app-lab/) -- JavaScript apps with buttons, screens, and data.
- [Game Lab](/guide/labs/game-lab/) -- sprite-based games and animations.
- [Sprite Lab](/guide/labs/sprite-lab/) -- block-based sprite stories and games.
- [Web Lab](/guide/labs/web-lab/) -- HTML and CSS websites.
- [Python Lab](/guide/labs/python-lab/) -- Python programming.
- [Java Lab](/guide/labs/java-lab/) -- Java programming.
- [Music Lab](/guide/labs/music-lab/) -- code-driven music composition.
- [Dance Party](/guide/labs/dance-party/) -- block-based dance animations.
- [Artist](/guide/labs/artist/) -- turtle graphics and drawing.
- [Maze and puzzles](/guide/labs/maze-and-puzzles/) -- block-based puzzle solving.
- [Play Lab](/guide/labs/play-lab/) -- interactive stories.
- [Minecraft](/guide/labs/minecraft/) -- Minecraft-themed coding activities.
- [Internet Simulator](/guide/labs/internet-simulator/) -- networking concepts.
