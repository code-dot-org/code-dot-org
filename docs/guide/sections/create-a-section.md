A section is how students join your class and see assigned work on CodeAI.

## Prerequisites

- A CodeAI teacher account.

## Create the section

1. On your teacher home page, select **New class section**.

   ![The "New class section" button on the teacher home page.](images/create-a-section-new-class-section-button.png)

2. Enter a name students will recognize, such as "Period 2 - Intro to CS".
3. Choose a login type. This controls how students sign in and cannot be changed later. See [Choose a login type](/guide/sections/choose-a-login-type/) for guidance.
4. Select the grade levels for your section.
5. Select **Save**.

CodeAI generates a six-letter section code (for example, ABCDEF). Share this code with your students so they can join at [code.org/join](https://code.org/join).

## Import from Google Classroom, Clever, or an LMS

Choose **Google Classroom** or **Clever** as the login type during section creation to sync your roster from the external service. See [Import a roster](/guide/sections/import-a-roster/).
