# Contract: Completion Artifact (FR-046 / FR-047)

A learner-triggered, teacher-collectable summary of one notebook session. Produced fully on-device; never round-trips through any server.

## Payload shape

```ts
interface CompletionArtifact {
  v: 1;                             // schema version
  sessionLabel: string;             // the human label the learner chose; PII boundary
  notebookId: string;               // UUIDv4
  notebookTitle: string;            // notebook.metadata.title fallback to filename
  unit?: string;                    // friendly unit name derived from metadata.folder
  generatedAt: number;              // epoch ms
  cells: ArtifactCell[];
}

interface ArtifactCell {
  cellId: string;
  kind: 'code' | 'markdown' | 'raw';
  runState: 'untried' | 'ran-ok' | 'ran-error' | 'n/a';
  lastOutput?: ArtifactOutput;
}

interface ArtifactOutput {
  kind: 'text' | 'html' | 'png' | 'svg' | 'error';
  /** Truncated preview. Text/HTML/error: ≤ 400 chars. PNG/SVG: ≤ 100 KB base64. */
  preview: string;
}
```

## Inclusion rules

| Field | Sourced from | Notes |
|---|---|---|
| `sessionLabel` | Active session label | Treated as PII for telemetry; OK in the artifact because the learner is intentionally exporting. |
| `notebookId`, `notebookTitle`, `unit` | Notebook record + manifest | `unit` is the friendly name, never the path string. |
| `generatedAt` | `Date.now()` at export | |
| `runState` | Derived from `cdo.runHistory` per cell | `n/a` for non-code cells. |
| `lastOutput` | Last `execute_result` or `error` on the cell | Text/HTML/error truncated at 400 chars; images truncated at 100 KB base64; a trailing `…` indicates truncation. |

## Exclusion rules (hard)

- **Cell source the learner typed**. The artifact MUST NOT contain `cell.source` for any cell. The empathy-card error summary IS allowed (it is system-rendered text describing the error, not learner input).
- **API keys**. (Moot in v1; defensive.)
- **`cdo.runHistory` raw timestamps** beyond the derived `runState`.
- **`metadata.globals` values** that the learner edited (curriculum-author-supplied defaults are allowed but not surfaced in v1 to keep the artifact small).

A unit test in `artifact/__tests__/artifactPayload.test.ts` MUST assert all five exclusion rules with a fixture notebook that contains each forbidden item.

## Encoding for QR

```
base64url( zlib( JSON.stringify(artifact) ) )
```

Embedded in a URL fragment so it never leaves the device:

```
https://studio.code.org/app/projects/notebook/artifact#artifact=<encoded>
```

Or in the Capacitor app:

```
capacitor://localhost/app/projects/notebook/artifact#artifact=<encoded>
```

QR code is rendered at module M (default `Medium`) with version chosen by the `qrcode` library based on payload length. The lab MUST surface a localized "QR is large — print to PDF instead" hint when the encoded length exceeds ~1.5 KB.

## Output formats

| Surface | Format |
|---|---|
| Web | Browser `window.print()` dialog with a print-only stylesheet → PDF |
| Native (iOS/Android) | Capacitor file save (PDF generated by the WebView's `printToPDF` if available, else a static image of the artifact view) |
| Teacher QR scan | Renders the read-only `CompletionArtifact` view in the teacher's browser at the artifact route |

## Artifact route render

When the route loads with a `#artifact=` fragment:

1. Decode the fragment (base64url → inflate → JSON.parse).
2. If the decoded payload's `v !== 1` or the schema validation fails, render a friendly "This artifact is from an incompatible version" message.
3. Render the read-only `CompletionArtifact` view.
4. Do not touch IndexedDB, do not register the SW route as needing offline data, do not initialize Pyodide.
5. After 5 minutes of inactivity, replace the route content with a "This artifact has been displayed long enough; please rescan if you need it again" message (defensive against shoulder-surfing in a classroom).

## Privacy posture

- The artifact contains exactly what FR-046 names: session label, notebook title, unit, per-cell completion state, last output per cell. Nothing more.
- The QR is a URL fragment — by HTTP semantics fragments never reach a server.
- The artifact's lifetime is the duration of the scan; no copy persists unless the teacher explicitly saves the URL.
- The lab MUST emit a telemetry event `nblab.artifact.shared` carrying only the cell count and the platform; no session label, no notebook id (hash if you need it), no preview content.

## Versioning

This contract is v1. Adding a new field to `ArtifactCell` is a MINOR bump and requires updating the artifact-view fallback rendering. Changing `v` is a MAJOR bump and may break older shares — communicate via release notes.
