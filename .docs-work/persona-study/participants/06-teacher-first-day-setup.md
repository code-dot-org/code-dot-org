# 06 — Teacher first day: create a section with picture passwords

**Verdict: HELPED**

## Path taken
- CodeAI Documentation (home) — 0 clicks (start)
- Choose a login type (Teachers > Classes) — 1 click
- Create a section (via Related link) — 2 clicks
- Managing your roster (via Next Steps link) — 3 clicks

## Answering sentence
- "Choose Picture. Each student signs in by clicking a sequence of pictures. No typing and no email address needed. You can print sign-in cards with each student's pictures."
- "CodeAI generates a six-letter section code (for example, ABCDEF). Share this code with your students so they can join at code.org/join."
- "Open the Login Info page from the section card. Select Print... Each card shows the student's name, the section code, and sign-in instructions."

## Confusion points
- Docs say "Picture" but product button reads "Picture password -- Recommended for ages 4-8." Same mismatch for "Word" vs "Secret words" and "Email" vs "Personal logins." A skimming teacher matching docs to buttons would hesitate.
- Docs say "select Create a section" but the real button is "+ New class section." Not the same string.
- Docs assume a teacher account is already set up. The signed-in account was actually a Student account; switching to Teacher popped an undocumented modal demanding email and marketing consent. Docs never mention this path.
- A rebrand promo banner ("Code.org is now CodeAI") created a full-page click-blocking backdrop that silently ate the first click on "New class section." Docs never mention this.

## Screenshots
None on any of the three pages (Choose a login type, Create a section, Managing your roster). A screenshot of the login-type picker with its real labels would have prevented the label-mismatch confusion. A screenshot of a printed login card would set expectations.

## Product test
Succeeded after detours. Created section "Room 12 - 2nd Grade" with Picture password login type. Got section code BLGLJZ. Added a test student "Alex." Printed login cards showing section code, student name, and assigned secret picture. Goal fully met.
