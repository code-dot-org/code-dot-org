## Not migrated (intentional)

- No MUI ThemeProvider: no design-system components used on the site
- Dark mode disabled: design-system dark tokens use a different attribute convention
- No custom landing page component: `docs/index.md` serves `/` directly

## Customizations beyond defaults

- `markdown.format: 'md'` -- content uses angle-bracket placeholders that MDX misparses
- `docs.include` (5 globs) -- content dir has legacy files at root; include-list simpler than exclude-list
- `docs.routeBasePath: '/'` -- docs-only site
- `@easyops-cn/docusaurus-search-local` -- local search, no Algolia account
- `colorMode.disableSwitch` -- no dark-mode token mapping
- `src/css/custom.css` (45 lines) -- Infima vars set to brand-purple, Geist, Space Grotesk

## Design system integration

- Fonts: Geist + Space Grotesk via @fontsource CSS imports (transitive from workspace)
- Colors: --ifm-color-primary = #7f4aa9 (brand-purple-60); shades from primitiveColors.css ramp
- Logo: code-org-logo.png from design-system-storybook
- No MUI, ThemeProvider, or component-library imports -- branding is CSS-only
