# phase3

Creates the remaining Kubernetes-side resources for the split cluster add-ons,
including the Argo CD app-of-apps bootstrap.

This phase consumes remote state from `../phase1/`, `../phase2/`, and
`../../codeai-k8s-dex/`. It does not create AWS resources directly.

The upstream Helm chart defaults now live under `./charts/`. The Helm releases
are static. The shared Argo CD and Dex OIDC client secret is generated by ESO
in `argocd` and pulled into `dex` through the Kubernetes provider.

`./charts/codeai-k8s/` is an umbrella chart that depends on the four local
wrapper charts and the two local Kargo webhook charts. It is a packaging
convenience, not the live Terraform install unit, because phase3 still
preserves multiple Helm releases across namespaces.

## Usage

```bash
find ./charts -mindepth 1 -maxdepth 1 -type d -exec sh -c 'cd "$1" && helm dependency build >/dev/null 2>&1 || true' _ {} \;
tofu init
AWS_PROFILE=codeorg-admin tofu apply
```

## Bootstrap inputs

Dex now consumes its Google OAuth client secret and Google service-account key
via ESO from AWS Secrets Manager. Phase3 no longer carries Dex-specific tfvars.
