# phase3

Creates the remaining Kubernetes-side resources for the split cluster add-ons,
including the Argo CD app-of-apps bootstrap.

This phase consumes remote state from `../phase1/` and reads the
`codeai-cluster-config` `ConfigMap` written by `../phase2/`.
It does not create AWS resources directly.

Local chart defaults live under `./infra/`.
The Helm releases are static. The shared Argo CD and Dex OIDC client secret is
generated by ESO in `argocd` and pulled into `dex` through the Kubernetes
provider.
ESO itself is now installed in this phase.
Gateway API CRDs are vendored in `./infra/gateway/crds/` and tracked with Git
LFS.

To refresh them after bumping `./infra/gateway/Chart.yaml` `appVersion`, run:

```bash
./infra/gateway/fetch-crds.sh
```

## Usage

```bash
find ./infra -mindepth 1 -maxdepth 1 -type d -exec sh -c 'cd "$1" && helm dependency build >/dev/null 2>&1 || true' _ {} \;
tofu init
AWS_PROFILE=codeorg-admin tofu apply
```

## Bootstrap inputs

Dex now consumes its Google OAuth client secret and Google service-account key
via ESO from AWS Secrets Manager. Phase3 no longer carries Dex-specific tfvars.
