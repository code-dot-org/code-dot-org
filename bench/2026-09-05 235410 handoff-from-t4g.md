## 4. Re-ranking under the new scope

The instruction on my side is *minimal* cleanup, weighted toward Graviton and
EC2 support. That is a different filter from "most broken", and it promotes
documentation over code. Proposed order, nothing started:

**1. SETUP.md, arm64 and current-distro section.** Highest leverage for the
stated goal and pure documentation. Covers the EC2 apt mirror — the default
`us-east-1.ec2.archive.ubuntu.com` served arm64 at 2 KB/s and stalled entirely,
against 8.5 MB/s from `ports.ubuntu.com`, which is the single largest time sink
either of us hit; `libyaml-dev`, absent from the apt list and required to build
Ruby 3.2; the gcc-13 Ruby, since GCC 15 on Ubuntu 26.04 produces a `config.h`
that breaks any gem forcing an older `-std`; arm64 Chrome, since
`chromium-browser` is a snap shim; `pdftk` having no arm64 candidate; and the
stale version table. Every one of these costs the next EC2 or Graviton user
hours.

**2. `ImageLibTest`, one line.** `test/lib/image_lib_test.rb:98` compares
`compare -metric ae` output to the string `'0'`; ImageMagick 7 prints `0 (0)`.
Not arm-specific, but Ubuntu dropped IM6 after 24.04, so every current host
fails these three. Cheapest real green-up available.

**3. B4 and the `docker/developers` README directory line.** Two lines.

**4. Your A.** Yours, one line plus a regression test.

EC2 and CI case. But the fix needs a maintainer's view on intended behaviour,
so I would raise it rather than patch it.
