# `copyright_trademark` rebrand — before/after by locale

Source key: `copyright_trademark` in `apps/i18n/common/<locale>.json`.

Only locales that already had this key are listed. Locales without the key
(`zh_cn`, `zh_tw`, `ar_sa`, `th_th`, `cs_cz`, `tr_tr`, `mr_in`, `or_in`,
`kn_in`, `ta_in`, `te_in`, `en_in`, `pt_pt`) fall back to English and were
left untouched.
