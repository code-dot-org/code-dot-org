# @code-dot-org/shared-constants

Ruby shared constants (`lib/cdo/shared_constants.rb`), committed as generated
TypeScript, for frontend packages that need them without Ruby.

`src/sharedConstants.ts` is generated by
`apps/script/generateSharedConstants.rb`, which also writes the
byte-identical `apps/generated-scripts/sharedConstants.ts` used by `apps/`.
That second copy is transitional: `apps/` still imports
`@cdo/generated-scripts/sharedConstants`, so the generator writes both
until those imports move to this package. The two copies never disagree —
one generator run writes both from the same content. This file is the one
committed to git, so CI checks it for drift
(`lib/rake/ci.rake`'s `check_for_new_file_changes` reruns the generator,
then checks this file for local changes).

Do not hand-edit `src/sharedConstants.ts`. To update it, change
`lib/cdo/shared_constants.rb` (or the files under
`lib/cdo/shared_constants/`) and run the generator:

```bash
cd apps && bundle exec ./script/generateSharedConstants.rb
```

Then commit the result.
