# `componentLibrary/checkbox`

## Consuming This Component

This package exports one styled React component: [Checkbox](Checkbox.tsx). You can import it like this:

```javascript
import Checkbox from '@code-dot-org/component-library/checkbox';
```

For guidelines on how to use these components and the features they
offer, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/designsystem-checkbox--docs).
Or run storybook locally and go
to [DesignSystem / Checkbox](http://localhost:6006/?path=/docs/designsystem-checkbox--docs).
