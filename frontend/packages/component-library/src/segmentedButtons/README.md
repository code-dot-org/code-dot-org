# `componentLibrary/segmentedButtons`

## Consuming This Component

This package exports one styled React component: [SegmentedButtons](SegmentedButtons.tsx).
You can import it like this:

```javascript
import SegmentedButtons from '@code-dot-org/component-library/segmentedButtons';
```

For guidelines on how to use these components and the features they
offer, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/designsystem-segmented-buttons--docs).
Or run storybook locally and go
to [DesignSystem / Segmented Buttons](http://localhost:6006/?path=/docs/designsystem-segmented-buttons--docs).
