# `component-library/accordion/faqAccordion`

## Consuming This Component

This package exports one styled React component: [FAQ](FAQAccordion.tsx).
You can import it like this:

```javascript
import FAQAccordion from '@code-dot-org/component-library/accordion/faqAccordion';
```

For guidelines on how to use this component and the features it
offers, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/designsystem-accordion-faq-accordion--docs).
Or run storybook locally and go
to [DesignSystem / Accordion / FAQ Accordion](http://localhost:6006/?path=/docs/designsystem-accordion-faq-accordion--docs).
