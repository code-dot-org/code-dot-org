# `componentLibrary/alert`

## Consuming This Component

This package exports one styled React component: [Alert](Alert.tsx).
You can import it like this:

```javascript
import Alert, {AlertProps} from '@code-dot-org/component-library/alert';
```

For guidelines on how to use this component and the features it
offers, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/designsystem-alert--docs).
Or run storybook locally and go
to [DesignSystem / Alert](http://localhost:6006/?path=/docs/designsystem-alert--docs).
