# `componentLibrary/label`

## Consuming This Component

This package exports one styled React component: [Label](Label.tsx). You can import it like this:

```javascript
import Label from '@code-dot-org/component-library/label';
```

For guidelines on how to use these components and the features they
offer, [visit Storybook](https://code-dot-org.github.io/dsco_)
(link to be updated once code-dot-org storybook will be public.).
Or run storybook locally and go to [Design System / Label](http://localhost:9001/?path=/story/designsystem-label--default-label).
