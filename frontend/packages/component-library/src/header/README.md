# `component-library/header`

## Consuming This Component

This package exports one styled React component: [Header](Header.tsx).
You can import it like this:

```javascript
import Header from '@code-dot-org/component-library/header';
```

For guidelines on how to use this component and the features it
offers, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/designsystem-header--docs).
Or run storybook locally and go
to [Design System / Header](http://localhost:6006/?path=/docs/designsystem-header--docs).
