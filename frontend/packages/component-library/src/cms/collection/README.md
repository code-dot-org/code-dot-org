# `component-library/cms/collection`

## Consuming This Component

This package exports one styled React component: [Collection](Collection.tsx).
You can import it like this:

```javascript
import Collection from '@code-dot-org/component-library/cms/collection';
```

_Note:_ This component is used primarily for the Contentful CMS.

For guidelines on how to use this component and the features it
offers, [visit Storybook](https://code-dot-org.github.io/code-dot-org/component-library-storybook/?path=/docs/cms-collection--docs).
Or run storybook locally and go
to [CMS / Collection](http://localhost:6006/?path=/docs/cms-collection--docs).
