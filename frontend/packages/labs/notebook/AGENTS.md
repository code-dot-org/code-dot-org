# @code-dot-org/notebook-lab

K-12 Python notebook lab. Pyodide runs entirely in a Web Worker — no server.

## Key constraints

- **No hex colors.** Use design-system tokens or MUI theme values only.
- **No TanStack Router imports.** The lab is a standalone package; `channelId`
  arrives as a prop from the studio route.
- **Do not hand-edit `routeTree.gen.ts`** (studio-side autogenerated file).
- **structuredClone guard.** Worker messages must be structuredClone-safe.
  Do not pass functions, class instances, or non-transferable objects.
- **PII in telemetry.** All telemetry must route through
  `src/telemetry/wrapper.ts`. Forbidden fields: session label, cell source,
  learner-supplied URLs, any string matching `/API[_-]?KEY/i`.
