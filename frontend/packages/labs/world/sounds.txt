# The stock sounds, as `name<TAB>url` (specs/SOUND.md).
#
# NAMED HERE, unlike backgrounds.txt, which carries URLs alone. A backdrop's
# upstream file name is already close to what a learner should read — `cave`,
# `city` — so it is derived. A sound's is not: the library's are
# `retro_game_coin_pickup_1` and `puzzle_game_organic_metal_tile_hit_1`, and
# camel-casing those gives a dropdown nobody can read. So the shelf says what
# each one is called and the URL says where it came from.
#
# A CURATED SUBSET. Upstream is 1598 sounds behind a 2.2MB manifest, served from
# the studio API; this lab vendors what it ships (`yarn setup:world` writes them
# into public/sounds/) because the standalone demo has no code.org origin to
# ask. Adding one is a line here and a re-run of
# `node scripts/write-stock-sounds.mjs`.
#
# Names are camelCase identifiers: an id becomes a file name (`jump.mp3`), a
# block's stored value, and generated source, and the writer refuses anything
# that is not.
