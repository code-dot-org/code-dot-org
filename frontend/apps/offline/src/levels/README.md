# Code.org Labs

This directory stores the code and resources for running the various activities
that make up the levels of the curricula. Most of the subdirectories from this
point are separate environments for such activities.

## Learning Activities

### Maze

These are the traditional Maze-type karel labs where the learner is asked to
navigate a character through a grid to an objective while, in some cases,
avoiding obstacles.

### Karel

This is a particular extension of the Maze and uses much of the same code where
the maze-guided character is asked to potentially perform other tasks while
navigating the maze.

### Artist

This is another traditional exercise where the learner controls a character that
draws lines, shapes, or other graphical elements on to a canvas as it moves. This
is sometimes referred to as a 'Turtle' application inspired by some of the
original exercises of this type using a turtle as its character.

### Sprite Lab

The Sprite Lab is a more advanced game-like environment that offers enhanced
character animation and interactive elements. This is particularly centered around
event-driven programming and logic.

## Content

### Standalone Video

These are just levels that encapsulate a video and a video player.

### Panels

Panels are a kind of 'slideshow'-style carousel of instructive content that help
explore or highlight content of upcoming activities.
