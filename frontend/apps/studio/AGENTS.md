# Code Studio

Studio is the host application — it has no exports and is never imported by other packages. Labs are loaded into it; it does not belong to them.

## Architecture

See [docs/architecture.md](./docs/architecture.md) for the Rails integration chain, init ordering, route tree generation, lab lazy-load boundary, and React singleton constraints.

## Key rules

- **Do not edit `src/routeTree.gen.ts`** — it is auto-generated by the TanStack Router Vite plugin on every build and `yarn dev`. Changes are overwritten.
- **Adding a lab requires two file changes** — `src/modules/labs/config/labs.ts` (add to `AVAILABLE_LABS`) AND `src/modules/labs/router/getLabEntrypoint.ts` (add the lazy import). Missing either causes a `notFound()` at the route level.
