# Code Studio

Studio is the host application — it has no exports and is never imported by other packages. Labs are loaded into it; it does not belong to them.

## Architecture

See [docs/architecture.md](./docs/architecture.md) for the Rails integration chain, init ordering, route tree generation, lab lazy-load boundary, and React singleton constraints.

## Key rules

- **All UI work goes through the design system.** Invoke the `design-system` skill before writing or modifying any UI and follow its guidance — it is authoritative on component choice, styling, and theming.
- **Do not edit `src/routeTree.gen.ts`** — it is auto-generated by the TanStack Router Vite plugin on every build and `yarn dev`. Changes are overwritten.
- **Adding a lab requires two file changes** — `src/modules/labs/config/labs.ts` (add to `AVAILABLE_LABS`) AND `src/modules/labs/router/getLabEntrypoint.ts` (add the lazy import). Missing either causes a `notFound()` at the route level.
- **Adding a course is one file change** — append a `CourseEntry` to `src/modules/catalog/courses.ts`. See "Adding a course vs. adding a module" below.
- **Lazy imports must use literal-string paths.** `lazy(() => import('@x'))` is fine. `lazy(() => import(\`./${var}\`))` silently fails at runtime in the signed iOS bundle because Vite can't analyze a templated path and never emits the chunk.
- **Service worker registration is gated on `!Capacitor.isNativePlatform()`** in `entrypoints/application.tsx`. Removing the gate breaks the Capacitor plugin bridge in the iOS / Android shell.

## Adding a course vs. adding a module

| You want to...                                          | Course | Module / Lab                           |
| ------------------------------------------------------- | ------ | -------------------------------------- |
| Show a card in the catalog                              | ✅     | (via a course entry that points at it) |
| Title, summary, cover, grade band                       | ✅     | ❌                                     |
| Run custom React on tap (drag-drop, video, training UI) | ❌     | ✅                                     |
| Land a new course without engineer review               | ✅     | ❌                                     |

**Course = content.** Non-engineer contribution. Today: append a TS entry. Future: drop `courses/<slug>/course.json` + `landing.mdx`.

**Module / lab = behavior.** Engineer contribution. Today: copy the `oceans` pattern (lab package + two registry edits). Future: `createModule({id, routes, slots})` declarative registration.

### Adding a course today

1. Open `src/modules/catalog/courses.ts`.
2. Append a `CourseEntry`. Pick exactly one of: `module + demoChannelId` (route to a lab), `externalUrl` (open existing studio.code.org), or neither (default `<CoursePage>` detail at `/app/courses/<slug>`).
3. Drop a cover at `src/config/brand/assets/courses/<slug>.webp` (placeholder logo is fine for stubs).
4. Open a PR. See `src/modules/catalog/README.md` for the author-facing version.

### Adding a course (future)

```
src/modules/catalog/courses/<slug>/
  course.json
  landing.mdx (optional)
  cover.webp
```

Discovered via `import.meta.glob`, validated by a Zod schema, rendered through a named `<Slot>` so engineer modules can override the default detail page.

## Mobile-first checklist

Before merging UI work:

- Touch targets ≥ 44×44 px
- No hover-only interactions (also support focus + tap)
- CSS grid / flex auto-flow rather than fixed-pixel layouts
- Tested at 375×812 (iPhone SE / mini) in Chrome device emulation
- Safe-area-inset padding visible in iPhone 14 Pro emulator (notch)

## iOS / Capacitor checklist

The web build is wrapped by `frontend/apps/mobile` as the native shell.
**For any mobile-app work, read
[`frontend/apps/mobile/docs/architecture.md`](../mobile/docs/architecture.md)** —
it covers the build modes (`build:mobile`), the SW gate, the sync flow,
lab integration patterns, and the known FIXMEs.

Quick reminders that apply to _any_ studio change:

- Templated dynamic `import()` paths (see Key rules above)
- Service worker registration without the `Capacitor.isNativePlatform()` gate
- `localStorage` for must-keep data — WKWebView evicts it aggressively. Use `@capacitor/preferences`.
- Remote code loading. Apple guideline 4.7 forbids fetching JS to eval; all module chunks must ship bundled inside the signed `.ipa`. (Vite's default lazy chunks are bundled — no change needed.)
