# @code-dot-org/mobile

The CodeAI mobile apps, packaged with [Capacitor](https://capacitorjs.com).
They open a landing page that lists the curricula, Studio's `/launcher`
route, and show the curricula themselves from studio.code.org in the same
WebView.

## Apps

- [Android](android/README.md), for Amazon Fire tablets (Amazon Kids+)

## Development

From `frontend/`, install dependencies once:

```bash
yarn install
```

Then, from this directory, serve the landing page in a browser:

```bash
yarn dev
```
