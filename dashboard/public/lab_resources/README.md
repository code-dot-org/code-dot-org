# Lab Resources
This folder contains resources for labs, such as placeholder images.
They are stored here so users have an easy URL to use.
On prod, items in this folder can be accessed via `studio.code.org/lab_resources/<filename>`.

## Image Optimizations

Images in this folder are not optimized at runtime. Please ensure images are pre-optimized prior to committing to this folder to improve end-user performance and reduce costs. General optimizations include:

1. Using AVIF or WEBP image formats.
2. Compressing images
3. Using the lowest quality that is acceptable for the use case.
